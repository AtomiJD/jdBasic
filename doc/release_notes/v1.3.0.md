# jdBasic 1.3.0

Range: `bd2eb677..v1.3.0` (everything after the 1.2 refresh of 26 October
2026, which shipped as the v1.2.0 assets). Facts only; each line names the
trakr ticket and the commit.

## New

- **Text that counts characters:** `LENW`, `MIDW$`, `LEFTW$`, `RIGHTW$`,
  `INSTRW` count UTF-8 characters where `LEN`/`MID$` count bytes (#921,
  53d96586).
- **`UCASE$` / `LCASE$` beyond ASCII:** Latin-1, Latin Extended-A, Greek and
  Cyrillic change case the same in both runtimes, so a case-blind compare of
  names with umlauts works (jdbook #840, 30e16b53).
- **`TXTWRITER` / `TXTENCODING$`:** `utf-16le-bom` and `utf-16be-bom`; the
  detected encoding name round-trips byte for byte, an append adds no second
  mark (#893, 7364d103).
- **Graphics:** `GFX.NEWTARGET` / `GFX.TARGET` draw into an image,
  `GFX.DRAWQUAD` places an image on any four corners (ed0579a5);
  `GFX.STROKE` draws thick lines with round ends (08f7a925); `GFX.LINES`
  draws many lines in one call (a503aa23); `GFX.NEWTARGET(w, h, FALSE)` keeps
  hard pixel edges (a57d99cb); fonts stay open per size and rendered `TEXT`
  is cached (0627dd66). `RASTER` draws SVG markers (91943c52).
- **Synth (packs with GFX):** `SOUND.SING` sings a lyric through a vocoder,
  a syllable a note (e71c520a, fcd8395b); `SOUND.VOCODER`; sampler
  `SOUND.SAMPLE`, `SOUND.SAMPLELOOP`, `SOUND.GRAIN` (#940); wavetables
  `SOUND.WAVETABLE` (#941); modulation matrix `SOUND.MATRIX`,
  `SOUND.MODLFO`, `SOUND.MODSRC` (#932); `SOUND.PARAM` and the `SYNTHPATCH`
  module for patches as JSON (#931); key zones with arpeggiator, chords and
  scale lock `SOUND.ZONE` / `SOUND.ZONESET` (#929, #936), `SOUND.PADMAP`
  (#934), `SOUND.INIT` takes a buffer size (#927).
- **Live audio and MIDI (builds with MINIAUDIO / MIDI, not in the four
  packs):** `MON.SYNTH` plays the synth on a miniaudio device, under 10 ms
  key to speaker in exclusive mode (#927); `MON.SYNTHIN` and `SOUND.INPUT`
  feed a live vocoder (#949); `MIDI.ROUTE` plays an input port on the synth
  inside the audio thread (#928), `MIDI.CLOCK` / `MIDI.CLOCKIN` (#937).
- **Forms:** `RICHTEXT` gets the VB6 RichTextBox formatting surface (`SEL*`,
  `TEXTRTF`, `SELRTF`, `RUNS`) (#902, 7ec06086); `FORM.PRINTRICH` prints a
  RICHTEXT as shown (#905, bacb076f).
- **Modules:** `MDRICH` (Markdown as editable rich text, #903, a09d9ad0), `MDSYNC`
  (Markdown source and RICHTEXT view in step, tables, #904, #916, 0daaf1fd),
  `TEXTX.FINDWORD` / `ISWORDCHAR` (#905); `TESTKIT 1.1` (a check after
  `REPORT()` throws, jdbook #885, ba769205); `PPTX 1.1` (`FIT_SCALE`,
  `BULLET_SCALE`, jdbook #838, e59462bc);
  `DT 1.1` (`OFFSET_AT`, jdbook #818, c968695e); `QR 1.1` (`HALF$`, jdbook
  #790, d56adc4e); `XLSX 1.1.0`
  (`XLSX.READ(path$, TRUE)` answers dates as text, e76f5472) and `XLSX 1.0.1`
  (character references, jdbook #799, 0514ee9f); `SVG 1.0.1` (`theme` option,
  umlauts in axis
  labels, c1731040); `LLMAPI` uses structured output on current Claude models (#909,
  503cac74).
- **`MATMUL` with a 3-D side** answers the product per batch, as `BMM` does,
  in both backends (#680, gh #11, 330e4ef5).
- **`STACK$`** names the whole call path with module and function
  (c1e2e48a).
- **`--lint`** lists a finding inside an IMPORTed module apart, "In imported
  modules, not counted" (jdbook #776, 45499d98).

## Changed

- **`SLEEP` waits to about half a millisecond on Windows** (a high-resolution
  timer instead of the 15.6 ms tick; `SLEEP 1` took 15 ms) (#948, 0d289128).
- **A FUNC or SUB defined twice in one file is an error** naming both lines
  (#924, 1420a71e).
- **TYPE:** a keyword cannot name a member (#919, e84a189f); under `-c` a
  member needs `AS <type>` (#920, 9866a222).
- **Compiled programs are per-monitor DPI aware** like `jdBasic.exe`, so
  screen sizes and cursor positions are physical pixels in both (jdbook
  #862, 7324a057).
- **A builtin that fails in a compiled program is named** in the error text
  as in the interpreter: `CSVREADER: Cannot open file: ...` (#965,
  b8574bd0).
- **An array in `IF` is read the same in both backends:** true when it has
  cells and every cell is true; an empty array is false (#964, b8574bd0).
- The mcp-native pack builds its runtime DLL with HTTP, so compiled programs
  of that pack have `HTTP.*` (jdbook #788, 7324a057).

## Fixed

- **Native compiler (`-c`), values whose kind only the run knows** - the
  divergence corpus of #912 went from 192 to 215 of 374 programs identical
  in both backends, plus the fixes found by the book's checks:
  - a text cell handed to a number parameter, a mixed array filled by PUSH
    in a FUNC (crashed), `IF` over an array or a regex match (#962, #963,
    #964, b8574bd0);
  - a cell of an untyped array handed to a builtin keeps its kind
    (`PATH.JOIN$(dir$, files[k])`, 1c996c6d); a cell added to a string is
    read with its own tag (5af347e2);
  - an element of `SORT` over a directory list, an array element in a map
    literal, a FUNC returning rows, a MAP function returning a JSON field
    (jdbook #794, #821, #844, 9287e7a1);
  - `APPEND(out, part)` answers a flat array (640073d8);
  - a RUNTIME array assigned to an array variable, `RETURN call()[0]`, IIF
    over map strings, an INTEGER sum or a FORM value into an untyped
    parameter (#906, #907, #910, #911);
  - JOIN of a VM cell in a FUNC (#913); matrix rows shifted in a FUNC
    crashed at random (#915, #922); a FUNC returning a UDT (#724);
  - an argument that raises goes to CATCH before the SUB or FUNC runs, and
    frees its strings (#945); a VM array read at an array of positions
    (#947); containers written into a parameter's container are counted
    (#925); a variable owning its texts stays owner (#914);
  - integers stay integer through funcrefs, ASYNC and runtime arithmetic;
    `m.x` on a map is NONE (#742, e76594c5);
  - a lambda called through a variable answers a text as a text
    (7601e7e0); a VM value on the left of `IN` (a0447031).
- **Interpreter:** a text operator with a constant on the right inside a
  FUNC or SUB works as at the top level (c60a1454).
- **`JSON.PARSE`:** a `\u` without four hex digits stays text, surrogate
  pairs become one character (#899, 77ea8efc).
- **`PDF.TEXT$`:** fonts in `/ObjStm` object streams (#900); no space after
  every glyph (#918); bounded glyph-width memory (beb04c00).
- **`FORMAT_DATE$`** with an unknown conversion raises an error on Linux and
  macOS too (#766, a651558b).
- **MCP server:** `OS.EXEC` gives the child NUL as stdin instead of the
  JSON-RPC stream (#767, 4bd3d563); `jdb_doc` finds `languages.md` for a
  server run from `build/` (#765, 0d25921d).
- `TXTREADER$` without an encoding leaves out a leading UTF-8 byte order
  mark (jdbook #768, 30e16b53).

## Known limits

- An untyped FUNC parameter is a number slot under `-c` when every call
  hands it a number or a cell the callee only reads as a number: a text
  there becomes its number (`"5" * 2` is 10 compiled, `55` interpreted)
  (#742).
- The `-c` divergence corpus still has about 76 programs that print
  something else compiled (#912).
