[DYNAMIC]
Syntax: FUNC f(p AS DYNAMIC) ...   |   DIM x AS DYNAMIC
Description: Tagged-mixed array — opt-in for FUNC params or DIM that
receive arrays built from `[m{"a"}, m{"b"}, ...]` (any array literal whose
elements are INDEX expressions). Stores per-cell JdTags so `p[i]` reads
return the correct type at runtime instead of bit-pun'ing every element
through a double. Without it, native compile drops every string element to
0 / loses every map handle.

literal is passed to a non-DYNAMIC parameter — annotate the param to fix.
Numeric arrays (e.g. `mem[]`, lookup tables) MUST stay un-annotated; AS
DYNAMIC on a plain numeric array forces the tagged-storage path and slows
reads with no benefit. Interpreter treats DYNAMIC like ARRAY.

[TXTWRITER]
TXTWRITER filename$, content$, [append], [encoding$]
Writes a string to a text file. The optional 3rd arg `append` (TRUE = append, default FALSE = overwrite). The optional 4th arg `encoding$` re-encodes the UTF-8 jdBasic string to the named codepage on disk; same name set as TXTREADER$. Binary mode, no newline translation. Roundtrip example:

    TXTWRITER "export.bas", src$, FALSE, "cp1252"

Description: Specifies the condition that must be true for a DO loop to continue.

[YIELD]
YIELD
Pauses execution and yields to the host environment's event loop for one frame.
