TITLE: 02 | If and For | Decisions and Loops

SAY: Hello again! It is Jaydee Basica. Welcome back to Train jdBasic, lesson two.

SAY: Last time we printed text and stored values in variables. Today we make our programs decide things, and repeat themselves. We will cover "if!" statements, and "for" loops.

SAY: Let us start with the simplest decision. Is something true?

TYPE: DIM age = 18
TYPE: IF age >= 18 THEN PRINT "You can vote!"
WAIT: 1.5

SAY: That is the inline form. The whole "if!" on a single line. Good for one quick check.

SAY: For anything longer we need the editor. The prompt only accepts one statement at a time. So I type the word "edit" and press enter to open the full screen editor.

TYPE: NEW
WAIT: 0.3
CMD: EDIT
WAIT: 0.2

TYPE: DIM age = 18
TYPE: IF age >= 18 THEN
TYPE: PRINT "You can vote!"
TYPE: PRINT "And drive."
TYPE: ENDIF
WAIT: 1.0

SAY: Now control-Q to leave the editor, and "run" to execute the program.

CMD: CTRL-Q
TYPE: CLS
TYPE: LIST
WAIT: 1.5
CMD: RUN
WAIT: 0.8

SAY: Every block-form "if!" ends with "end-if". No exceptions.

SAY: To handle the "otherwise" case, add an else branch.

TYPE: NEW
WAIT: 0.3
CMD: EDIT
WAIT: 0.2

TYPE: DIM hour = 22
TYPE: IF hour < 12 THEN
TYPE: PRINT "Good morning"
TYPE: ELSE
TYPE: PRINT "Good evening"
TYPE: ENDIF
WAIT: 0.8

CMD: CTRL-Q
TYPE: CLS
TYPE: LIST
WAIT: 1.5
CMD: RUN
WAIT: 0.8

SAY: Since the hour is twenty-two, the else branch ran.

SAY: One last variant. "Else-if" chains multiple conditions.

TYPE: NEW
WAIT: 0.3
CMD: EDIT
WAIT: 0.2

TYPE: DIM hour = 14
TYPE: IF hour < 12 THEN
TYPE: PRINT "Good morning"
TYPE: ELSEIF hour < 18 THEN
TYPE: PRINT "Good afternoon"
TYPE: ELSE
TYPE: PRINT "Good evening"
TYPE: ENDIF
WAIT: 0.8

CMD: CTRL-Q
TYPE: CLS
TYPE: LIST
WAIT: 1.8
CMD: RUN
WAIT: 0.8

SAY: jdBasic walks the branches top to bottom and runs the first one that matches.

SAY: Now "for" loops. The classic shape: do something a known number of times.

TYPE: NEW
WAIT: 0.3
CMD: EDIT
WAIT: 0.2

TYPE: FOR i = 1 TO 5
TYPE: PRINT "Hello "; i
TYPE: NEXT i
WAIT: 0.8

CMD: CTRL-Q
TYPE: CLS
TYPE: LIST
WAIT: 1.2
CMD: RUN
WAIT: 1.0

SAY: The variable i counts from the start value to the end value, inclusive. Five iterations, five greetings.

SAY: You can step by something other than one. Even backwards.

TYPE: NEW
WAIT: 0.3
CMD: EDIT
WAIT: 0.2

TYPE: FOR i = 10 TO 0 STEP -2
TYPE: PRINT i
TYPE: NEXT i
WAIT: 0.8

CMD: CTRL-Q
TYPE: CLS
TYPE: LIST
WAIT: 1.2
CMD: RUN
WAIT: 1.0

SAY: Counting down by two. Step also accepts fractional values for double-precision loops.

SAY: Now let us combine "if!" and "for". Here is fizz-buzz, the classic interview warm-up.

TYPE: NEW
WAIT: 0.3
CMD: EDIT
WAIT: 0.2

TYPE: FOR i = 1 TO 15
TYPE: IF i MOD 15 = 0 THEN
TYPE: PRINT "FizzBuzz"
TYPE: ELSEIF i MOD 3 = 0 THEN
TYPE: PRINT "Fizz"
TYPE: ELSEIF i MOD 5 = 0 THEN
TYPE: PRINT "Buzz"
TYPE: ELSE
TYPE: PRINT i
TYPE: ENDIF
TYPE: NEXT i
WAIT: 1.0

CMD: CTRL-Q
TYPE: CLS
TYPE: LIST
WAIT: 3.0
CMD: RUN
WAIT: 1.8

SAY: There it is. Every multiple of three prints fizz, every multiple of five prints buzz, and multiples of both print fizz-buzz.

SAY: That is everything for lesson two. To recap: inline "if!" for one quick check at the prompt. "Edit", then "run", for anything bigger. "If!", "else-if", and "else" to decide. "For" and "next" to repeat.

SAY: In lesson three we introduce arrays, and a bit of the magic that makes jdBasic special. Vector operations that work on whole arrays at once, with no "for"-loop in sight.

SAY: Until then! Keep coding. Bye!
