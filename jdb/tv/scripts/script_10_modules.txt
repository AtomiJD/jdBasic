TITLE: 10 | Modules | Code Worth Reusing

CHAPTER: Welcome to the finale
SAY: Welcome back to the final lesson of Train jdBasic. Jaydee here. Lesson ten.

SAY: We have covered a lot. Today we tie it all together. We will write our first reusable module, save it as its own file, then import it from a brand-new program and use the functions inside.

SAY: A module is just a jdBasic file that begins with "export module" and a name. Any "func" or "sub" you mark with "export" becomes callable from outside under that name.

CHAPTER: Writing a module
SAY: Let us write one.

TYPE: NEW
WAIT: 0.3
CMD: EDIT
WAIT: 0.2

TYPE: EXPORT MODULE MATHX
TYPE:
TYPE: EXPORT FUNC CLAMP(x, lo, hi)
TYPE:     IF x < lo THEN RETURN lo
TYPE:     IF x > hi THEN RETURN hi
TYPE:     RETURN x
TYPE: ENDFUNC
TYPE:
TYPE: EXPORT FUNC PERCENT(part, whole)
TYPE:     RETURN (part / whole) * 100
TYPE: ENDFUNC
WAIT: 1.0

CMD: CTRL-Q
TYPE: CLS
TYPE: LIST
WAIT: 3.0

SAY: A tiny math toolbox. "clamp" keeps a value between a low and a high bound. "percent" computes a percentage. Both are marked "export" so other files can call them.

CHAPTER: Saving the module to disk
SAY: Now we save the buffer to disk under the module's file name. Lowercase.

TYPE: SAVE mathx
WAIT: 1.0

CHAPTER: IMPORT + dotted calls
SAY: One file written to disk. Now a fresh program that uses it.

TYPE: NEW
WAIT: 0.3
CMD: EDIT
WAIT: 0.2

TYPE: IMPORT MATHX
TYPE:
TYPE: PRINT MATHX.CLAMP(15, 0, 10)
TYPE: PRINT MATHX.CLAMP(-5, 0, 10)
TYPE: PRINT MATHX.CLAMP(7, 0, 10)
TYPE: PRINT MATHX.PERCENT(75, 200)
WAIT: 0.8

CMD: CTRL-Q
TYPE: CLS
TYPE: LIST
WAIT: 2.0
CMD: RUN
WAIT: 1.8

SAY: "import" loads the module and makes its exports available under the module name. Fifteen clamped to the range zero to ten becomes ten. Minus five becomes zero. Seven stays seven. And seventy-five out of two hundred is thirty-seven point five percent.

SAY: That is how you organise code. Drop related functions into a module, save the file, and any program in the same folder can pull them in with one line.
