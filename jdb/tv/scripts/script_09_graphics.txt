' ──────────────────────────────────────────────────────────────────
'  Lesson 09 - Graphics
'  Topic: SCREEN to open a window, DRAWCOLOR, RECT, CIRCLE, LINE,
'         SCREENFLIP to display, render loop (SCREENFLIP + SLEEP)
'         with an ON "QUIT" handler so the close button works.
'
'  Recording note: this lesson uses OBS scene switching.  The script
'  flips to a "Desktop" scene (cropped 0,0,1920x1080 of the display)
'  while the SDL window is on screen, and the director's WINMOVE
'  command snaps the freshly-opened SDL window to that 1920x1080
'  area so it lands exactly inside the crop region.  Between demos
'  we switch back to "IDE" (window-capture of jdBasic) and FOCUS
'  back on the IDE so the next TYPE: reaches the right window.
'
'  Why a render loop instead of SLEEP 3500: a flat SLEEP blocks the
'  whole VM, so the SDL window never gets its WM_WINDOWPOSCHANGING
'  serviced and Windows refuses to move it.  SCREENFLIP polls SDL
'  events itself, so flipping every 16 ms keeps the message pump
'  alive, WINMOVE settles into the new position, and the canvas
'  accumulates, so re-flipping the same content does not flicker.
'
'  Target runtime: ~6 minutes
' ──────────────────────────────────────────────────────────────────

CHAPTER: First circle
SAY: Let us start with the smallest possible drawing program.

TYPE: NEW
WAIT: 0.3
CMD: EDIT
WAIT: 0.2

TYPE: DIM running = 1
TYPE: SUB OnQuit()
TYPE:     running = 0
TYPE: ENDSUB
TYPE: ON "QUIT" CALL OnQuit
TYPE:
TYPE: SCREEN 600, 400, "Lesson 09"
TYPE: DRAWCOLOR 255, 220, 0
TYPE: CIRCLE 300, 200, 80, TRUE
TYPE: FOR f = 0 TO 220
TYPE:     IF running = 0 THEN EXITFOR
TYPE:     SCREENFLIP
TYPE:     SLEEP 16
TYPE: NEXT f
TYPE: GFX.CLOSE
WAIT: 0.5

CMD: CTRL-Q
TYPE: CLS
TYPE: LIST
WAIT: 2.5

SCENE: Desktop
CMD: RUN
WINMOVE: Lesson 09
WAIT: 4.5
SCENE: IDE
FOCUS: jdBasic

SAY: A yellow circle in the middle of a six-hundred by four-hundred window. The "circle" command takes a centre point, a radius, and a boolean. True means filled, false would draw only the outline. The render loop flips the screen every sixteen milliseconds for about three and a half seconds, and the on-quit handler lets the close button end the program early.

CHAPTER: Drawing in a loop
SAY: Because every drawing command is a regular jdBasic statement, you can put them inside loops. Watch.

TYPE: NEW
WAIT: 0.3
CMD: EDIT
WAIT: 0.2

TYPE: DIM running = 1
TYPE: SUB OnQuit()
TYPE:     running = 0
TYPE: ENDSUB
TYPE: ON "QUIT" CALL OnQuit
TYPE:
TYPE: SCREEN 600, 400, "Loop"
TYPE: DRAWCOLOR 0, 0, 0
TYPE: RECT 0, 0, 600, 400, TRUE
TYPE: FOR i = 0 TO 9
TYPE:     DRAWCOLOR 255 - i * 25, 100, i * 25
TYPE:     CIRCLE 60 + i * 55, 200, 25, TRUE
TYPE: NEXT i
TYPE: FOR f = 0 TO 220
TYPE:     IF running = 0 THEN EXITFOR
TYPE:     SCREENFLIP
TYPE:     SLEEP 16
TYPE: NEXT f
TYPE: GFX.CLOSE
WAIT: 0.8

CMD: CTRL-Q
TYPE: CLS
TYPE: LIST
WAIT: 3.0

SCENE: Desktop
CMD: RUN
WINMOVE: Loop
WAIT: 4.5
SCENE: IDE
FOCUS: jdBasic

SAY: Ten circles in a row, each a different colour, drawn by a single "for" loop. The colour shifts smoothly from red toward purple as the index grows.
