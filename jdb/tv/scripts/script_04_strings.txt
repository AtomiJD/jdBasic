TITLE: 04 | Strings | Text the Right Way

CHAPTER: Welcome
SAY: Welcome back. Jaydee here. Lesson four.

SAY: We have done numbers. We have done arrays. Today: strings. Pieces of text, and how to slice, search, and reshape them.

CHAPTER: Concatenation + LEN
SAY: Concatenation first. Use plus to glue two strings together.

TYPE: DIM first$ = "Jaydee"
TYPE: DIM last$ = "Basica"
TYPE: PRINT first$ + " " + last$
WAIT: 0.8

SAY: Variables ending with a dollar sign hold strings. That is a BASIC convention from the seventies that jdBasic keeps for readability.

TYPE: PRINT LEN(first$)
WAIT: 0.6

SAY: "len" works on strings too. Six characters in "Jaydee".

CHAPTER: LEFT$, RIGHT$, MID$
SAY: To grab parts of a string, use "left", "right", or "mid". All three end with a dollar sign because they return strings.

TYPE: PRINT LEFT$("Hello, World!", 5)
TYPE: PRINT RIGHT$("Hello, World!", 6)
WAIT: 1.0

SAY: The first five characters from the left. The last six from the right.

TYPE: PRINT MID$("Hello, World!", 7, 5)
WAIT: 1.0

SAY: "mid" takes a start position and a length. And one important detail positions are zero-based. Position zero is the first character. Same convention as arrays.

CHAPTER: INSTR$ - find substring
SAY: To find one string inside another, use "instr".

TYPE: DIM pos = INSTR$("Hello, World!", "World")
TYPE: PRINT pos
WAIT: 0.8

SAY: Seven. The substring "World" starts at the eighth character, which is index seven.

SAY: If the substring is not found, "instr" returns minus one.

TYPE: PRINT INSTR$("Hello", "xyz")
WAIT: 0.6

CHAPTER: UCASE$ / LCASE$ / TRIM$
SAY: Case changes are easy.

TYPE: PRINT UCASE$("hello")
TYPE: PRINT LCASE$("WORLD")
WAIT: 0.8

SAY: Upper case, lower case. And "trim" removes leading and trailing whitespace.

TYPE: PRINT TRIM$("   spaces around   ")
WAIT: 0.8

SAY: Useful when you read input from a file or the user, and you do not know how clean it is.

CHAPTER: SPLIT - string to array
SAY: One last trick. "split" takes a string and a delimiter, and returns an array of pieces.

TYPE: DIM parts = SPLIT("red,green,blue", ",")
TYPE: PRINT parts
TYPE: PRINT parts[1]
WAIT: 1.2

SAY: Three colours separated by commas. "split" gave us back an array of strings. Element one is "green".

CHAPTER: CSV mini-parser
SAY: Now let us combine everything in a small program the kind of thing you would write to parse a line out of a text file.

TYPE: NEW
WAIT: 0.3
CMD: EDIT
WAIT: 0.2

TYPE: DIM line$ = "Atomi,38,Heidelberg"
TYPE: DIM parts = SPLIT(line$, ",")
TYPE: PRINT "Name:  "; parts[0]
TYPE: PRINT "Age:   "; parts[1]
TYPE: PRINT "City:  "; parts[2]
TYPE: PRINT
TYPE: PRINT UCASE$(parts[0]); " lives in "; parts[2]
WAIT: 0.5

CMD: CTRL-Q
TYPE: CLS
TYPE: LIST
WAIT: 1.8
CMD: RUN
WAIT: 1.5

SAY: A single line of CSV-style text, split into three fields, then combined into a sentence. The same pattern handles real-world text files line by line.
