TITLE: 05 | Functions and SUBs | Code You Can Name

CHAPTER: Welcome
SAY: Welcome back. Jaydee here. Lesson five.

SAY: Until now everything we wrote ran top to bottom in one stretch. Today we learn to name a piece of code and call it whenever we want. Two flavours "func" for code that returns a value, and "sub" for code that just acts.

CHAPTER: FUNC + RETURN
SAY: Let us start with a simple function.

TYPE: NEW
WAIT: 0.3
CMD: EDIT
WAIT: 0.2

TYPE: FUNC Twice(x)
TYPE:     RETURN x * 2
TYPE: ENDFUNC
TYPE: PRINT Twice(5)
TYPE: PRINT Twice(7)
TYPE: PRINT Twice(100)
WAIT: 0.5

CMD: CTRL-Q
TYPE: CLS
TYPE: LIST
WAIT: 1.8
CMD: RUN
WAIT: 1.2

SAY: "func" "twice" of x. The word "return" hands a value back to whoever called us. "end-func" closes the block. Then we call "twice" three times with different numbers and print each result.

CHAPTER: Multiple parameters
SAY: Functions can take more than one parameter.

TYPE: NEW
WAIT: 0.3
CMD: EDIT
WAIT: 0.2

TYPE: FUNC Add(a, b)
TYPE:     RETURN a + b
TYPE: ENDFUNC
TYPE: PRINT Add(3, 4)
TYPE: PRINT Add(10, -2)
WAIT: 0.5

CMD: CTRL-Q
TYPE: CLS
TYPE: LIST
WAIT: 1.5
CMD: RUN
WAIT: 1.0

SAY: Two parameters separated by a comma. Same idea.

CHAPTER: SUB - actions, no return
SAY: For a subroutine you skip "return" entirely a "sub" performs an action and ends. Useful for tasks like printing a banner.

TYPE: NEW
WAIT: 0.3
CMD: EDIT
WAIT: 0.2

TYPE: SUB Greet(name$)
TYPE:     PRINT "Hello, "; name$; "!"
TYPE:     PRINT "Welcome aboard."
TYPE: ENDSUB
TYPE: Greet("Atomi")
TYPE: Greet("World")
WAIT: 0.5

CMD: CTRL-Q
TYPE: CLS
TYPE: LIST
WAIT: 1.8
CMD: RUN
WAIT: 1.5

SAY: One "sub" called twice with different names. Notice the call site looks the same as a function call name in front, arguments in parentheses.

CHAPTER: Local scope
SAY: Variables defined inside a function or a sub are local. They vanish when the call returns. That keeps your code clean and predictable.

CHAPTER: Recursion - Fibonacci
SAY: For the finale, here is a classic. Fibonacci numbers, computed by a function that calls itself.

TYPE: NEW
WAIT: 0.3
CMD: EDIT
WAIT: 0.2

TYPE: FUNC Fib(n)
TYPE:     IF n < 2 THEN
TYPE:         RETURN n
TYPE:     ENDIF
TYPE:     RETURN Fib(n - 1) + Fib(n - 2)
TYPE: ENDFUNC
TYPE: FOR i = 0 TO 10
TYPE:     PRINT Fib(i); " ";
TYPE: NEXT i
TYPE: PRINT
WAIT: 0.5

CMD: CTRL-Q
TYPE: CLS
TYPE: LIST
WAIT: 2.5
CMD: RUN
WAIT: 1.5

SAY: "fib" of n. If n is less than two, return n. Otherwise return "fib" of n minus one, plus "fib" of n minus two. The first eleven Fibonacci numbers zero, one, one, two, three, five, eight, and so on. Recursion in three lines of jdBasic.
