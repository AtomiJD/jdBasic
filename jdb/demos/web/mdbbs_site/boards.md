 B O A R D S
========================================

 ---- Adafruit Fruit Jam --------------

 RP2350B, 320 by 240 over a real HDMI
 socket, USB host for keyboard and
 pads, eight megabytes of PSRAM, and
 an ESP32-C6 for the network.

 About seventy kilobytes are free for
 a program. The compiler is what
 spends them, which is why compiled
 programs are worth their while here.

 ---- PicoCalc ------------------------

 RP2350 with a 320 by 320 panel, its
 own keyboard and an SD card. A whole
 computer in a case, with jdBasic as
 the thing that greets you.

 ---- ESP32-S3 ------------------------

 Headless, over a serial line. WiFi
 built in. About two hundred kilobytes
 free with PSRAM fitted.

 ---- Bare metal ----------------------

 No operating system. jdBasic is the
 operating system: it boots, it draws,
 it reads the keyboard, it runs your
 program.

 ---- What they share -----------------

 The same prompt, the same editor, the
 same names for everything. A program
 written on one is a program the next
 one runs.
