{cyan} ---- Adafruit Fruit Jam --------------{/}

 RP2350B, 320 by 240 over a real HDMI
 socket, USB host for keyboard and
 pads, eight megabytes of PSRAM, and
 an ESP32-C6 for the network.

 About {white}two hundred kilobytes{/} are free
 at the prompt, and the PSRAM holds
 the arrays. A program built on a
 desktop as p-code starts at once.

{cyan} ---- PicoCalc ------------------------{/}

 RP2350 with a 320 by 320 panel, its
 own keyboard and an SD card. A whole
 computer in a case, with jdBasic as
 the thing that greets you. About
 {white}350 kilobytes{/} free at the prompt.

{cyan} ---- ES3C28P, an ESP32-S3 ------------{/}

 A 2.8 inch panel with touch, a codec
 with speaker and microphone, a card
 slot, WiFi built in. About {white}230
 kilobytes{/} free at the prompt and
 eight megabytes of PSRAM beside it.

{cyan} ---- Bare metal ----------------------{/}

 No operating system. {magenta}jdBasic is the
 operating system{/}: it boots, it draws,
 it reads the keyboard, it runs your
 program.

{cyan} ---- What they share -----------------{/}

 The same prompt, the same editor, the
 same help, the same names for
 everything. Ctrl-C ends a program on
 each of them. A program written on
 one is a program the next one runs.
