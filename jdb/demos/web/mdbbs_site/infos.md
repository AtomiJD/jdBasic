 ---- What jdBasic is -----------------

 A BASIC that kept the things the old
 ones got right and dropped the rest.
 Line numbers are gone. Arrays are
 whole values you can add, reshape and
 reduce without writing a loop.

 It runs three ways: interpreted for
 the quick answer, compiled to a real
 executable when speed matters, and as
 p-code on boards too small to hold a
 compiler.

 ---- The idea behind it --------------

 Coding on the open heart. A program
 you can reach into while it is
 running, change, and watch carry on.
 That is what the old machines had and
 what most of what came after lost.

 ---- Arrays are the point ------------

```
 a = IOTA(10)
 PRINT SUM(a * a)
 PRINT REVERSE(a)
```

 No loop, no index variable. The
 operators go through the array.

 ---- Where it runs -------------------

 Windows, Linux, macOS, a browser via
 WebAssembly, a Raspberry Pi RP2350,
 an ESP32, and bare metal with no
 operating system underneath at all.
