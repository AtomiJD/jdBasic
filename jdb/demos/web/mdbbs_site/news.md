{cyan} ---- Ctrl-C --------------------------{/}

 A running program ends on Ctrl-C, on
 every board, wherever it is: in a
 loop, inside a SLEEP, while a web
 server waits. It says {white}Break at line
 N{/} and the prompt is back.

{cyan} ---- The editor ----------------------{/}

 Find, find next, replace. Undo. A
 line longer than the screen scrolls
 sideways. Ctrl-R saves, runs, and
 comes back. Word jumps, block indent,
 duplicate and delete a line. {white}F1{/}
 lists the keys.

{cyan} ---- Room ----------------------------{/}

 Free at the prompt: PicoCalc {white}351 KB{/},
 Fruit Jam {white}209 KB{/}, ES3C28P {white}229 KB{/} and
 8 MB of PSRAM beside it. The builtin
 names live in flash. SYS.STACK says
 how deep the stack went, SYS.NATIVES$
 lists every builtin by name.

{cyan} ---- The lessons ---------------------{/}

 The Train jdBasic lessons sit on every
 board in a lessons folder. TYPE
 lessons/readme.txt lists them. They
 are here too, under {orange}Lessons{/}.

{cyan} ---- Two demos -----------------------{/}

 {white}NET CLOCK{/}: the time from the network,
 the weather from Open-Meteo, an
 analog and a digital face, colour
 schemes, on any board with a radio.
 {white}JAM SESSION{/}: text, PETSCII, graphics,
 sound, the five LEDs and the three
 buttons of the Fruit Jam in one
 program.

{cyan} ---- One console ---------------------{/}

 The same forty columns on every
 board, the same UTF-8 glyphs, the
 same PETSCII block from CHR$(152) up.
 CURSOR 0 hides the cursor, CURSOR 1
 shows it.

{cyan} ---- Programs that skip the compiler -{/}

 A program built on a desktop with
 {white}jdbasic --pcode{/} and copied across
 starts {green}at once{/}. The file carries the
 names of the builtins it calls and
 the board resolves them; one the
 board does not have is refused by
 name.

{cyan} ---- Controllers ---------------------{/}

 A USB pad is a joystick under the
 same names a desktop uses, so a game
 written against a controller on a PC
 runs on the Fruit Jam unchanged.
