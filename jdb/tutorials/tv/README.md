# Train jdBasic - lesson samples

Standalone code samples from the Train jdBasic video lessons, one file per
editor/REPL segment. Generated by `jdb/tv/extract_samples.jdb` from the
lesson scripts in `jdb/tv/scripts/` - do not edit these files by hand;
change the lesson script and regenerate:

```
cd jdb/tv
jdbasic extract_samples.jdb
```

The extractor writes this folder and `wasm/programs/tv/` (the web playground
copy, which skips lessons 13/14 - the wasm build has no HTTP flag and no
OS.EXEC). `mathx.jdb` is the lesson 10 module; `lesson10_modules_b.jdb`
IMPORTs it, so both must stay in the same folder.

Delete the folder before regenerating if lesson files were renamed - the
extractor overwrites but never removes stale samples.
