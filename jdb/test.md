# Welcome to jdBasic Markdown Renderer

This document demonstrates the capabilities of the renderer.
It supports various formatting options, such as:

 - *Italics* for emphasis.
 - **Bold** for strong importance.
 - ***Bold and Italic*** for really strong importance.
 - `Inline code` for short snippets.

## Code Blocks

You can include multi-line code blocks:
```jdbasic
FOR i = 1 TO 10
    PRINT 'Hello, World #'; i
NEXT i
```

---

> Blockquotes are also supported. They are great for quoting text from other sources.
