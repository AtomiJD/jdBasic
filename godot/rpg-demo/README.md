# jdBasic RPG Demo

A small Godot 4.6 project that shows what the jdBasic-as-script integration
can do: procedural terrain, NPCs with FSM behaviour, and LLM-driven
character dialog generated by a local Phi-3-mini running in jdBasic.

Showcases:

- `terrain_gen.jdb` builds a 192x192 heightmap via APL-style vector math
  (4 octaves of layered sin/cos, zero FOR loops).
- `npc_brain.jdb` runs Idle/Patrol FSMs for 4 NPCs, hot-editable while
  the game is playing.
- `dialog_brain.jdb` runs a prefetch loop: ASYNC FUNC + AI.CHAT generates
  greetings for NPCs within 30m of the player, so dialog feels instant.
- Per-NPC persona / legend / knowledge / quest data lives in JSON, so
  adding a new character is a JSON edit, not a code change.

## Bootstrap

Two things have to be staged before the project will run.

### 1. KayKit Adventurers pack

The 6 character models and shared animation set come from KayKit
Lousberg's free Adventurers pack. Download:

  https://kaylousberg.itch.io/kaykit-adventurers

Extract into `godot/Assets/KayKit_Adventurers_2.0_FREE/`, then copy:

    cp godot/Assets/KayKit_Adventurers_2.0_FREE/Characters/gltf/*.glb \
       godot/rpg-demo/assets/characters/

    cp godot/Assets/KayKit_Adventurers_2.0_FREE/Animations/gltf/Rig_Medium/*.glb \
       godot/rpg-demo/assets/animations/

The whole pack is gitignored - it's ~117 MB and not redistributable
via this repo.

### 2. LLM-enabled jdBasic runtime

The Godot extension needs `jdbrt.dll` compiled with `LLM`, plus the
llama.cpp / CUDA runtime DLLs. From the repo root:

    .\build_rt.bat LLM

This drops everything into `build/`. Copy them into the addon:

    cp build/jdbrt.dll build/llama.dll build/ggml*.dll \
       build/cublas64_12.dll build/cublasLt64_12.dll build/cudart64_12.dll \
       godot/rpg-demo/addons/jdb_godot/bin/

The `bin/` folder is gitignored - all rebuildable from source.

### 3. Phi-3 GGUF model

Default path in `world.gd` is `D:/usr/dev/cc/models/Phi-3-mini-4k-instruct-q4.gguf`.
If you keep yours elsewhere, edit `model_path` on the World node in the
inspector, or download the model:

  https://huggingface.co/microsoft/Phi-3-mini-4k-instruct-gguf

`Phi-3-mini-4k-instruct-q4.gguf` (~2.4 GB) is what we tested with on a
RTX 4070 Ti SUPER, ~200 tok/s.

## Run

Open `project.godot` in Godot 4.6 and press F5. First boot loads the
LLM into VRAM (~1-2s on GPU, ~10s on CPU). After that:

- WASD walks, mouse orbits the camera, Shift runs, Space jumps.
- Walk towards an NPC. Their nameplate flips to `Name  ...` while
  the dialog worker generates their greeting, then to `Name  ✓`.
- The generated line prints in the editor console with `[dialog] <id>: ...`.

Phase 4 (E-to-talk dialog UI + quest parsing) is in progress; see
`embed/godot/ROADMAP.md`.
