Arrays & matrices

An array is a value, not a container you walk. Whole-array operations are the shortest path and usually the fastest one.

Shapes and ranks

Every array carries its shape. IOTA(5) is a vector of five elements, RESHAPE turns it into a matrix. Ranks above two work the same way; nothing is special-cased for 1 < rank < 4. 

DIM v = IOTA(5)
DIM m = RESHAPE(v, [5, 1])
PRINT SHAPE(m)          ' [5, 1]

An index that is out of bounds is an error, never a silent zero.

Slicing

Rows

A row comes out as an array of its own: 

DIM row = m[1]
PRINT row[0] <= row[1]

Cells

A cell reads with two indices. Mixing the two forms is allowed inside one expression, which is why m[1][0] and m[1, 0] mean the same thing.

FormReadsWrites
m[i]a rowyes
m[i, j]a cellyes
m[ , j]a columnno

Reducers

Reducers take an array and answer one value: SUM, MEAN, MIN, MAX. They are not two-argument functions — MAX(a, b) reads the second argument as an axis. 

PRINT SUM([1, 2, 3])    ' 6
PRINT MAX([a, b])       ' the larger of the two

A loop over an array is the fallback, not the first move.

Pitfalls

Copying
A bare assignment may share storage; force a copy element by element.
Growing
Use PUSH for one element and APPEND for many.
